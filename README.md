# Marketing-Channel-Analytics
Excel dashboard for marketing channel performance and profitability analysis
## Marketing Channel Analytics Dashboard
This project analyzes marketing performance across different acquisition channels using Microsoft Excel.
The dashboard compares channel-level performance across key marketing KPIs and provides an overview of overall campaign performance.
### Channels Analyzed 
- Affiliate
- Display
- Paid Search
- Paid Social
- Video
### Key KPIs
- Revenue
- Spend
- Profit
- ROAS (Return on Ad Spend)
- ROI (Return on Investment)
- CTR (Click-Through Rate)
- Conversion Rate
- CPC (Cost Per Click)
- CPA (Cost Per Acquisition)
### Dashboard Analysis
The dashboard provides: 
- Overall marketing performance KPIs
- Profit comparison across channels
- ROI comparison across channels
- Revenue share by channel
- CTR by channel
- CPC by channel
- CPA by channel
- Overall conversion performance
### Tools & Techniques 
- Microsoft Excel
- PivotTables
- PivotCharts
- Calculated Fields
- Excel Formulas
- KPI Analysis
- Data Visualization
- Marketing Performance Analysis
### Project Objective
The objective of this project is to evaluate marketing channel performance using key efficiency and conversion metrics, identify differences between acquisition channels, and present the results through an interactive Excel dashboard. 
### Files 
- `Marketing Channel Analytics.xlsx` — Excel workbook containing the source data, PivotTables, calculations, and dashboard. - `dashboard-image.png` — Dashboard preview.
### Key Formulas 
**Profit** 
`Revenue - Spend` 
**ROAS** 
`Revenue / Spend` 
**ROI** 
`(Revenue - Spend) / Spend` 
**CTR** 
`Clicks / Impressions` 
**Conversion Rate** 
`Conversions / Leads` 
**CPC** 
`Spend / Clicks` 
**CPA** 
`Spend / Conversions`
